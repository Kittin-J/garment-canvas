# seedream-5-0-260128

产品范围：普通图片生成节点，支持文生图和参考图编辑或融合。

## 请求

- 统一端点：POST /v1/images/generations，application/json。
- model 固定为 seedream-5-0-260128。
- 不传 image 为文生图；image 为 URL 或 data URI 数组时进入编辑模式。
- 参考图最多按上游 10 张校验，但本项目产品上限为 8 张，因此首轮最多 8 张。
- size 仅允许 2K 或 3K；不得向该模型发送 1K 或 4K。
- response_format 可为 url 或 b64_json；本项目显式选择一种，不依赖默认值。
- watermark 必须显式为 false。
- OpenAI 的 n 参数会被静默忽略，禁止发送。
- 单图输出时 sequential_image_generation 固定为 disabled。
- 若后续开放序列生成，必须使用 sequential_image_generation=auto 和 max_images，并满足输入图加输出图不超过 15；首轮普通节点不依赖该能力。
- 建议调用超时至少 120 秒，并由 Worker 长请求配置统一兜底。

## 响应

- response_format=url 时读取 data[].url，并立即转存；链接通常约 24 小时内有效。
- response_format=b64_json 时读取不带 data URI 前缀的纯 Base64。
- data[].size 是实际输出尺寸，可能与请求档位略有差异，必须记录实际尺寸。
