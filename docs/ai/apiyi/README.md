# API易图片模型本地知识库

最后核对：2026-08-20

本目录是 garment-canvas 接入 API易图片接口的实现基准。它只保留本项目需要的请求契约、约束、错误语义和来源指纹，不复制上游整页文档，也不保存 API Key、提示词或图片内容。`sources.json` 的 SHA-256 针对 `markdownUrl` 返回的完整响应体，可用于确认本地整理契约对应的上游版本。

## 本轮模型范围

| 模型 | 产品用途 | 可用节点 |
| --- | --- | --- |
| gpt-image-2 | OpenAI 官转蒙版编辑 | 仅“蒙版局部重绘”节点 |
| gpt-image-2-vip | 通用生成与参考图编辑 | 图片生成节点 |
| gemini-3.1-flash-image | 通用生成与多图编辑 | 图片生成节点 |
| flux-2-pro | 通用生成与最多 8 图融合 | 图片生成节点 |
| seedream-5-0-260128 | 通用生成与最多 10 图融合 | 图片生成节点 |
| grok-imagine-image | 通用生成与最多 4 图编辑 | 图片生成节点 |

产品范围比上游能力更窄时，以本表为准。尤其是 gpt-image-2：上游也支持文生图和普通编辑，但本项目首轮只能由蒙版节点选择。

## 文件说明

- **model-contracts.json**：实现与测试读取的机器可读契约。
- **async-runtime.md**：业务异步队列、重试、恢复、取消和结果转存规则。
- **input-image-normalization.md**：用户上传素材进入节点和生成队列前的标准化硬门禁。
- **models/**：每个模型的人工可读适配说明。
- **sources.json**：上游 canonical URL、官方 Markdown URL、抓取日期、SHA-256 指纹以及对应的本地整理文档。

原始页面不作为仓库文件保存。`models/`、`async-runtime.md` 和 `model-contracts.json` 是经过项目范围收窄后的本地知识库；实现与测试只依赖这些本地契约。

## 实现约束

1. API易图片接口本身均为同步长请求，不存在可轮询的上游 task_id。项目异步能力必须由 PostgreSQL 任务表和 Worker 提供。
2. 节点必须显式保存模型 ID；服务端不得用全局模型开关覆盖单个节点的选择。
3. 所有模型参数先在本地严格校验。不得依赖上游的静默回退或静默忽略行为。
4. 仅明确的 HTTP 429 和可重试 503 最多自动重试 2 次。连接超时、连接重置、响应中断等结果不确定场景标记为 outcome_unknown，不自动重放，避免重复计费。
5. URL 输出必须由 Worker 立即下载到项目自有存储，再写入历史记录。前端不得长期依赖第三方临时 URL。
6. 自动化测试只能使用假 Provider，不得调用任何付费模型。
7. 保持现有鉴权、项目归属、素材归属、最多 8 张产品引用图及无拉伸缩放规则。模型自身上限更低时取更低值。
8. 产品模型 ID 与上游请求模型 ID 分开保存。请求 URL 和请求体只能读取 `model-contracts.json` 的 `upstreamModelId`，不得假设二者永久相同。
9. 用户上传图片必须先完成 `inputNormalization` 契约并落盘，接口返回 `normalized: true` 后前端才能写入节点。原始上传字节不得直接传给模型。

## 文档优先级

发生冲突时按以下顺序处理：

1. 本目录的产品范围和安全约束。
2. sources.json 对应的 API易模型页面。
3. API易通用图片最佳实践。
4. 历史接入文档。

docs/ai/gpt-image-2-lmu.md 描述的是灵眸网关，已被本目录取代，不得用于 API易实现。
